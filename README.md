# 📦 Supply Chain Management – Data Analytics Project

## Project Overview
This project delivers a comprehensive, end-to-end analysis of supply chain operations using a dataset of **12,000+ orders**. It provides an integrated view across five key dimensions — **orders, revenue, inventory, transportation, and delivery performance** — to uncover actionable business insights that drive operational efficiency.

## Objective
To transform raw supply chain data into meaningful insights by analyzing regional demand patterns, transportation modes, lead times, sales trends, and delivery performance using a multi-tool analytics approach.

## Key Highlights
- Analyzed **12,000 orders** to identify patterns in regional demand, transportation efficiency, and delivery performance
- Built interactive dashboards to monitor KPIs such as on-time delivery, inventory levels, and revenue by region/city
- Performed SQL-based analysis to deep-dive into order trends, carrier performance, and lead time variations
- Identified **Product Design** as the leading category by volume and revenue
- Delivered data-driven recommendations for improving delivery, optimizing transportation modes, and enhancing inventory planning

## Tools & Technologies
- **Advanced Excel** – Data cleaning, transformation, and preliminary analysis
- **MySQL** – Querying, aggregation, and structured data analysis
- **Power BI** – Interactive dashboards and KPI tracking

## Key Recommendations
- Improve on-time delivery by analyzing delayed orders across carriers, regions, and ship modes
- Optimize high lead-time transportation modes (Sea & Rail) through better routing and mode allocation
- Strengthen inventory planning with regular stock monitoring and reorder tracking
- Focus resources on high-volume regions and high-revenue cities for warehouse and fulfillment optimization
